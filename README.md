# Scoop bucket for repoke

[repoke](https://repoke.paveldelpozo.es) finds the package managers on your system and keeps them up to date.

```powershell
scoop bucket add paveldelpozo https://github.com/paveldelpozo/scoop-bucket
scoop install paveldelpozo/repoke
```

`scoop update repoke`, or `repoke self-update`, keeps it current. The manifest is written by repoke's release script with each release.
